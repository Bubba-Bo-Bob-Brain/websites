Sentinel Engine

High-performance distributed task orchestration framework for real-time data pipelines.

✔ Build Passing ◉ 94% Coverage ⬡ v3.1.8 ⚖ MIT License

Overview

Sentinel Engine provides fault-tolerant, horizontally-scalable task scheduling with built-in observability. Designed for microservice architectures processing millions of events per second.

npm install @nexus-core/sentinel-engine

Quick Start

import { Sentinel } from '@nexus-core/sentinel-engine';

const sentinel = new Sentinel({
  cluster: 'production-us-east',
  workers: 8,
  heartbeat: 5000,
});

sentinel.on('task:complete', (result) => {
  console.log('Pipeline output:', result);
});

await sentinel.start();
