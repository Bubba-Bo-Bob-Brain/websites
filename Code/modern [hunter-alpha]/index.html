CodeVault Frontend App

A modern, performant React application built with TypeScript, featuring server-side rendering, real-time updates, and an accessible design system.

✨ Features

  • ⚡ Server-side rendering with streaming
  • 🎨 Design system with 50+ components
  • 🔐 OAuth2 & JWT authentication
  • 📊 Real-time dashboard analytics
  • 🌙 Dark & light theme support
  • ♿ WCAG 2.1 AA accessibility

🚀 Quick Start

bash 
# Clone the repository
git clone https://github.com/codevault/frontend-app.git
cd frontend-app

# Install dependencies
npm install

# Start development server
npm run dev
